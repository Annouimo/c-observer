1. 恢复测试基线。运行 gofmt、go test ./...、go vet ./...。已知 TestSampledLineHistory（setup_test.go:75）仍假设默认源码视图，应先显式进入源码视图再按 H；检查其他失败日志，不删测试规避。
2. 主界面：彻底取消常驻左源码右数据分栏。顶部少量执行上下文（空间允许约三行源码）、变化摘要、进度；全部剩余主要空间交给全宽数据区。完整源码、调用栈、输入输出按需访问。
3. 渲染：普通变量紧凑多列；短数组横向索引网格，长数值纵向索引列表；矩阵子表、结构体数组共享表、嵌套结构体内部重要字段直接呈现（例如并行数组）；低优先级技术信息用紧凑摘要。根据真实字符宽度生成完整/紧凑/概览候选，自动选择。
4. 布局：同时考虑宽高，先为所有顶层对象分配最低可读空间，再完整展示小对象、扩充大型对象预览。先横排、紧凑表达，再缩减预览，最后才整体滚动。禁止按声明容量隐藏对象，不固定等宽栏。利用完整历史预分析列宽及范围，普通数值变化不改变布局；当前帧及已记录全局/静态数据默认可见，其他帧按需查看，可靠身份区分递归同名变量。
5. 交互：日常左右键回放，保留首尾、指定步、历史筛选、重跑、输出对照；详情能继续回放并查看全部已采集数据。清理旧最大化及常驻分栏逻辑，统一帮助、快捷键、对象选择、Esc 返回。反向/直接跳转同一步的变化语义一致。
6. 真实性：明确区分已采集未展示、未采集、无法读取、截断；完整原值可查。仅可靠身份且两端可比较时标变化；不猜测初始化、访问位置、逻辑长度、业务含义。保留采集页调整与重跑、异常/取消/结束语义。
