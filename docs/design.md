# TUI 设计规范（草案）

## 观察主界面
默认单屏、只读、历史回放优先。宽屏左侧源码、右侧数据；下方紧凑输入输出；底部状态/历史位置/操作提示。窄屏采用区域切换，不将代码及数组硬压进不可读列。终端大小变化保留选择与历史位置。避免多层卡片边框、大标题和常驻菜单。

源码使用真实 C 词法高亮（注释、字符串、关键字等）；源码行号与逻辑文件映射；突出当前暂停位置，不称其为“刚执行完”的行。选中光标与执行位置区分。固定使用该次运行的源码快照，重新运行才重新读取磁盘。

变量以作用域/栈帧分组，默认显示当前局部及参数；全局视能力展示。名称、类型、值、前值；基于相邻采集快照比较，不按用户跳转前的页面比较。同名变量由身份标识区分；变量离开作用域不等于值清零。不要把任意读取到的内存值称作已初始化。
- 字符串：文本转义，标出截断；可展开字符。
- 一维数组：下标与元素；大数组有限范围，明确显示容量/实际采集范围，不猜有效长度。
- 结构体：字段列表；结构体数组：共享字段表格，嵌套内容可展开。
- 未采集、不可访问、截断分别标识，历史不能凭空展开当时未记录的值。
- P1 可选：二维矩阵、变量变化历史、代码行命中历史、调用栈切换。

输入为给定样例全文；不承诺精确消费位置（stdio 缓冲）。输出为已捕获字节前缀，注明缓冲可能延迟；stderr 单独呈现。预期输出可选，未提供时不显示判定。正常结束、崩溃、超时、取消、采集截断分别显示，均保留已有快照。

## 交互
- 左/右：全局前后快照；上/下：当前焦点内部选择或滚动；Tab/Shift+Tab：区域焦点；Enter：展开/详情；Home/End：历史首尾（文本输入控件除外）；R：重新运行；Esc：关闭详情或返回；采集中提供取消键与提示。P1：Space 播放/暂停，H 历史索引。
- 采集过程默认跟随最新快照；用户主动向后浏览即停止自动跟随，End 恢复跟随。采集与 UI 不阻塞；结束后自由回放。
- 独立启动支持源文件和样例输入；外部调用直接进入观察界面。重新运行保留输入及仍有效的观察设置。无源码编辑。
- 退出前停止后端并清理进程。失败时给可操作原因，不把异常后留存的快照当完整运行。

## 视觉
使用终端主题、ANSI 兼容色及文字标记，不只依赖颜色；绿色表示观测到的值变化、红色错误、黄色限制、灰色辅助。焦点和当前行用光标/背景，区别于变化色。底部随焦点提示可用按键。中文路径、中文 UI、宽字符对齐和无色终端需测试。采用 Bubble Tea / Lip Gloss，依赖具体版本待前端分支选择。

## 测试
至少覆盖正常/空历史、流式追加、用户浏览时继续采集、异常终止、数组截断、作用域同名、未采集值、窄终端、重新运行和取消。前端使用显式标记的 synthetic fixtures，不依赖安装 GDB。
