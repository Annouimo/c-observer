# TUI 设计规范

本阶段采用 docs/frontend-next.md 的批准方案。当前实现为体验版，仍待真机验收；以 docs/interface.md 的阻塞 Engine.Run / RunResult 语义为准。

## 工作台
单屏只读回放，默认源码与数据约 1:1 双栏、底部输入与输出、固定快照编号/导航模式/操作提示；窄屏按 Tab 切换，M 最大化/恢复。运行过程中显示状态、耗时、取消；完整结果返回才建立索引进入回放。不伪造采集进度。结束状态不是真实快照。

当前执行位置与源码浏览光标分开；选择调用栈帧时显示该帧的源码与变量、标记其为所选上下文；身份不可靠时回到栈顶。代码使用轻量词法高亮、行号、横向移动，源码冻结于当次运行。

## 数据
按参数、局部、静态、全局等已有作用域信息展示，身份未知时保守降级。基本变量采用名称/类型/值紧凑行；字符串内容优先；小型数组直接展示下标和值、结构体字段列表、结构体数组共享表格、矩阵行列。较大对象保留摘要与详情、复杂嵌套可用树。按真实展示成本判断，不能根据声明容量决定折叠。
可靠变化与原始相邻快照比较，前端不推断初始化、访问或逻辑长度。未记录、无法读取、截断不同，缺失数据不能填零。

## 关注范围
一次索引整个已采集历史。可靠变化下标的最小闭区间扩展两端各 2 项；二维变化包围矩形四周各 1 行列。结构体数组中任意可靠字段变化计入该元素。限制在采集边界，范围固定、缺失项明确；极稀疏大间隔使用缺失区间占位而非分配巨大表。无可靠变化时完整展示。V 可切换完整/自动，O 手动指定已采集区间，A 改采集页并重跑。历史范围不支持补采，可靠身份仅在本次运行内有效。

## 交互
方向键时间/局部导航，Tab 区域，Enter 详情或确认，Esc 返回或取消，R 重跑，Q 退出。F 四种导航模式，J 直接跳快照，H 对象/选中行历史，S 栈帧，M 最大化，O 对象菜单，? 帮助。D/A/V/T 保留快捷入口。筛选只改变导航目标，不改变快照编号或比较基准。显示历史数据时保持选中对象、栈帧与原始停靠语义。

## 输入输出和启动
默认输入、实际输出同时显示。控制台可切换错误、预期与对照；最终输出单独展示，逐字节比较并可见化空白，不等于 OJ 判定。长行折行，截断明确；异常保留已有历史。独立配置页支持源路径补全、样例粘贴/文件导入、预期输出选填。Companion/CLI 可通过 NewLive 跳过配置。工具链错误由诊断显示，不自行更改 PATH。

## 视觉与验收
终端主题、克制边框；蓝色暂停/焦点、绿色可靠变化、黄色限制、红色错误/差异、灰色辅助；符号配合颜色。宽窄终端、中文宽字符、长路径、长值和回放布局稳定性必须测试。使用合成夹具和明确标识的真实记录，不混淆。测试与 CI 构建不替代真机 UI 审核。
