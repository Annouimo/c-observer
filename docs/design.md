# 下一代 Observer 前端设计：数据优先的时间回放

状态：开发规范，取代此前动态源码/分组表格方案。旧方案仅由 Git 历史保留，不再作为产品功能。

## 目标与取舍

替代 printf 调试：学生希望知道程序运行到某处时数据是什么，而不是阅读另一份源码或配置专业调试器。尽可能少的操作获取尽可能多的有效信息，屏幕优先展示重要数据；视觉焦点稳定。单一主界面，无平行观察模式。无价值功能删除，而非降级到菜单。

## 单一工作区

顶部紧凑运行信息，下方左右并列约三行执行上下文与本次最终样例输入/预期/实际输出；完整源码和逐行输出对比临时查看，不常驻。主区域尽可能全宽展示当前帧局部变量与已记录全局/静态数据；底部固定观察进度条。输入输出从运行结果入口临时查看；不另设执行记录、状态观察、动态源码或全程概览页面。

每次展示同一个真实快照 S(t)，时间是原始观察次序，不是运行耗时或严格语句步数。默认从首个可用观察开始；空记录明确显示原因。结束不是额外快照。首帧显示初始暂停点；其后以原始前一暂停点为区间起点并标注至当前暂停点，数据为区间结束状态。不声称起点语句独立造成变化。前后差异始终比较原始相邻快照，不因跳跃/反向拖动而改变。

## 数据布局

- 标量紧凑排列，数组保留真实下标，二维数值数组用矩阵，结构体用成员表，结构体数组用共享成员列。嵌套对象递归展示。
- 布局尽可能使用整次记录的名称、类型、形状预分析，以保持模块位置、列和下标稳定；预分析只能决定坐标，不能补填当前时刻的值。当前无对应根对象以 — 表示，未知成员以 ?，不可读明确标识，截断/部分采集可见。
- 同时呈现主要对象；大型数据模块内部滚动，避免挤走其他对象。先保证数据可读，再增加展示密度。标量及元素当前值为主体，变化用中性强调色；名称/类型/技术信息弱化。选择用边框，和当前变化高亮独立。
- 同一函数上下文内保持模块坐标，其他函数局部对象不占空间。局部名称按函数与名称近似匹配，全局按名称及已知分类。同名多候选不任意取一；无法比较的状态不伪装成变化或不变。调用深度、位置上下文、类型及已有可靠 ID、声明和作用域冲突参与比较守卫，不声称严格身份。

## 时间线与数据联动

原生可拖动滑块贯穿工作区宽度，拖动过程更新所有数据及源码；支持左右键相邻观察、首尾与观察编号精确定位。点击数据模块本身或其成员/元素，切换唯一关注对象；再次点击取消。不额外设置变量选择器，不打开历史页面。时间线标记该对象所有可比较的相邻观察变化；容器为任意可比较后代的变化并集，点击成员缩小粒度。标记归属后一观察。上/下一变化跳转至真实观察；大量标记可在像素尺度重叠，不能合成虚假观察。无比较证据不等于无变化；首次采集、消失、缺失、无法读取、截断不算已知值变化。选中对象在当前时刻缺失仍保留关注。

## 删除范围

原型中的源码主表、手动观察列、循环轮次和展开、函数调用分组、行号查询、独立时间顺序/状态页、跨时刻最近值概览、数据历史详情页及其专用逻辑均删除。完整原始记录与现有后端契约仍保留；不为了界面构造 AST、运行时身份系统或控制流图。

## 验收

默认零配置展示真实快照，拖动实时同步，重点信息一眼可见；数据坐标在不同观察间稳定。点击根或成员无需另开页面，变化标记与跳转准确，反向/跳跃一致；未采集与不存在、截断可辨。使用错误下标、排序、矩阵、结构体查找、递归和长记录进行验证；合成记录明确标识，真实课程记录与原生 Mac/Windows 验收分开。开发阶段自动构建 Apple Silicon Mac，Windows 按需手动构建，正式发行前双平台验证。

## 布局优化

标量紧凑键值排列，模块按历史形状与数值宽度估算自然宽度，不强制等宽填满。大型一维数组优先保留变化元素与邻近下标，连续至少四个历史稳定且值相同的真实下标可折叠，当前值缺失/不可比较/发生变化时不折叠；点击区间展开。未采集下标不虚构，矩阵不折叠空间结构。复杂模块内部滚动，全部已记录值可查（长值标题提示）。原始快照仍完整。首轮不建设通用布局求解器、任意范围配置或采集策略。

时间线将标记与滑块共用轨道坐标；按需缓存有限数量对象的事件索引，绘制层最多约千个标记位置，前后跳转仍使用精确观察编号。样例规则与原始字节逐行比较分开；异常退出或截断不得显示为一致。开发验收加入旧 adaptive-array / data-first-stress 夹具；合成数据不替代原生视觉或真实课程验收。
