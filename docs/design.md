# 下一代 Observer 前端设计：数据优先的时间回放

状态：开发规范，取代此前动态源码/分组表格方案。旧方案仅由 Git 历史保留，不再作为产品功能。

## 目标与取舍

替代 printf 调试：学生希望知道程序运行到某处时数据是什么，而不是阅读另一份源码或配置专业调试器。尽可能少的操作获取尽可能多的有效信息，屏幕优先展示重要数据；视觉焦点稳定。单一主界面，无平行观察模式。无价值功能删除，而非降级到菜单。

## 单一工作区

顶部紧凑运行信息，下方左右并列约三行执行上下文与本次最终样例输入/预期/实际输出；完整源码和逐行输出对比临时查看，不常驻。主区域尽可能全宽展示当前帧局部变量与已记录全局/静态数据；底部固定观察进度条。源码、样例各自作为唯一直接点击入口，状态在样例内就地显示；不另设执行记录、状态观察、动态源码或全程概览页面。

每次展示同一个真实快照 S(t)，时间是原始观察次序，不是运行耗时或严格语句步数。默认从首个可用观察开始；空记录明确显示原因。结束不是额外快照。首帧显示初始暂停点；其后以原始前一暂停点为区间起点并标注至当前暂停点，数据为区间结束状态。不声称起点语句独立造成变化。前后差异始终比较原始相邻快照，不因跳跃/反向拖动而改变。

## 数据布局

- 标量紧凑排列，数组保留真实下标，二维数值数组用矩阵，结构体用成员表，结构体数组用共享成员列。嵌套对象递归展示。
- 布局尽可能使用整次记录的名称、类型、形状预分析，以保持模块位置、列和下标稳定；预分析只能决定坐标，不能补填当前时刻的值。当前无对应根对象以 — 表示，未知成员以 ?，不可读明确标识，截断/部分采集可见。
- 同时呈现主要对象；大型数据模块内部滚动，避免挤走其他对象。先保证数据可读，再增加展示密度。标量及元素当前值为主体，变化用中性强调色；名称/类型/技术信息弱化。选择用边框，和当前变化高亮独立。
- 同一函数上下文内保持模块坐标，其他函数局部对象不占空间。局部名称按函数与名称近似匹配，全局按名称及已知分类。同名多候选不任意取一；无法比较的状态不伪装成变化或不变。调用深度、位置上下文、类型及已有可靠 ID、声明和作用域冲突参与比较守卫，不声称严格身份。

## 时间线与数据联动

原生可拖动滑块贯穿工作区宽度，拖动过程更新所有数据及源码；支持左右键相邻观察、首尾与观察编号精确定位。点击数据模块本身或其成员/元素，切换唯一关注对象；再次点击取消。不额外设置变量选择器，不打开历史页面。时间线标记该对象所有可比较的相邻观察变化；容器为任意可比较后代的变化并集，点击成员缩小粒度。标记归属后一观察。上/下一变化跳转至真实观察；大量标记可在像素尺度重叠，不能合成虚假观察。无比较证据不等于无变化；首次采集、消失、缺失、无法读取、截断不算已知值变化。选中对象在当前时刻缺失仍保留关注。

## 删除范围

原型中的源码主表、手动观察列、循环轮次和展开、函数调用分组、行号查询、独立时间顺序/状态页、跨时刻最近值概览、数据历史详情页及其专用逻辑均删除。完整原始记录与现有后端契约仍保留；不为了界面构造 AST、运行时身份系统或控制流图。

## 验收

默认零配置展示真实快照，拖动实时同步，重点信息一眼可见；数据坐标在不同观察间稳定。点击根或成员无需另开页面，变化标记与跳转准确，反向/跳跃一致；未采集与不存在、截断可辨。使用错误下标、排序、矩阵、结构体查找、递归和长记录进行验证；合成记录明确标识，真实课程记录与原生 Mac/Windows 验收分开。开发阶段自动构建 Apple Silicon Mac，Windows 按需手动构建，正式发行前双平台验证。

## 布局优化

标量紧凑键值排列，模块按历史形状与数值宽度估算自然宽度，不强制等宽填满。大型一维数组优先保留变化元素与邻近下标，连续至少四个历史稳定且值相同的真实下标可折叠，当前值缺失/不可比较/发生变化时不折叠；点击区间展开。未采集下标不虚构，矩阵不折叠空间结构。复杂模块内部滚动，全部已记录值可查（长值标题提示）。原始快照仍完整。首轮不建设通用布局求解器、任意范围配置或采集策略。

时间线将标记与滑块共用轨道坐标；按需缓存有限数量对象的事件索引，绘制层最多约千个标记位置，前后跳转仍使用精确观察编号。样例规则与原始字节逐行比较分开；异常退出或截断不得显示为一致。开发验收加入旧 adaptive-array / data-first-stress 夹具；合成数据不替代原生视觉或真实课程验收。

## 视觉表达与样式

能由空间结构、对齐、形状、边框、状态标记或适当动效准确表达的语义，不重复用常驻文字解释。未知值用 ?、无对应根对象用 —，含义由对应对象悬停/可访问提示提供，不设常驻图例；数组已显示完整坐标时不重复提示缺失数量，未显示的采集范围仍需简短可见提示。技术详情通过标题提示等按需访问；不得因精简隐去关键状态，也不单靠颜色区分。名称、数值等查错信息优先完整显示。样例常驻预览每项限制为一行，换行用 ↵、制表用 ⇥，超长截断，原始内容在完整对比保留。

源码方向动效已通过维护者体验验收，正式保留：同文件相邻观察之间按真实区间起点行号方向短距离滚动，前进和回退的方向由行号差决定；同一行、跨文件、大跨度定位不播放；普通拖动及小范围跳转也保留方向滚动，快速拖动缩短动画并取消前一动画；响应系统减少动态效果偏好，取消旧动画，不延迟数据更新、不伪造中间执行。其用途是传达移动方向而非装饰。

样式采用原生控件、现有 CSS 变量与少量规则，统一间距、字号、边界和状态反馈；不引入组件库、不建设独立设计系统或为装饰增加成本。设计参考 NN/g 可用性启发式（https://www.nngroup.com/articles/ten-usability-heuristics/）、Apple HIG Motion（https://developer.apple.com/design/human-interface-guidelines/motion）、WCAG 2.2 的颜色与交互动效要求（https://www.w3.org/WAI/WCAG22/quickref/）。原则用于减少干扰和保障可读性，不宣称完整符合无障碍标准。

## 界面审查与语义动效

每个常驻元素必须承担独立的查错价值；同一功能只留一个可见入口，状态归属对象附近，不另设重复按钮或说明。仅单一数据组时省略分组标题；真实下标无需标题；未显示覆盖范围、异常、合成记录等必要限定仍保留。样例详情默认逐行对比，原始文本按需切换而非同时铺陈；异常与 stderr 只在存在时展示。

时间线删除六个外围导航按钮、常驻说明和统计；点击轨道自由定位，点击轨道上方标记带时命中附近真实事件（密集时取最近、等距取较早），拖动不吸附，滚轮/触控板累计微调，左右键逐步、Shift+左右键跳变化、Home/End 首尾，编号点击输入。绘制压缩不影响精确事件索引。保持键盘焦点和无障碍标签。暂不做缩放。

动效只传递方向、变化、空间关系或操作反馈。源码方向滚动保留；标记更新短淡入（实际标记路径重新出现，不插值位置）；主动展开压缩区间短过渡；相邻观察真实可比较叶值变化瞬时反馈为实验（双向、超过 12 项全部禁用，快速拖动/大跳转禁用）。动画不阻塞数值，不插值或推断交换过程，新的操作取消旧动画，遵循减少动态效果设置。通常 100–250ms；不添加装饰性动效或设置面板。以实际数据和原生体验为验收依据。

回放动效触发必须与主要交互路径一致：区分直接定位、拖动/滚轮、精确编号跳转；方向动效独立于数据瞬时强调，不能因启用拖动而整体禁用。快速连续拖动缩短源码滚动、抑制数值闪动；慢速相邻拖动仍反馈真实叶值变化。回归测试覆盖正反向拖动、快速拖动、小范围点击与精确跳转。

## 真实数据展示与统一关注

仅两个观察状态：当前观察时刻、关注对象。点击模块或成员统一驱动变化标记与按需详情；重复点击、数据区真实空白和 Esc 取消。源码、样例、时间线、滚动不取消。详情由关注根对象派生，成员关注保留父对象上下文；普通标量或完整小对象不显示额外面板。右侧固定比例详情与同一时间线共享 DataModule，原始形状完整展示，主区稳定有限预览；省略真实坐标仍需可见数量。详情短局部淡入位移，回放不做布局动画，遵循减少动效。取消旧压缩区间专用展开状态，由关注详情代替；不展示原始 JSON 或调试器内部属性。

字符数组以实际连续已采集字符及 NUL 为依据生成字符串摘要；未见终止符只称前缀/摘要，剩余缓冲区用弱化样式而非异常标记。指针保留地址，只呈现后端已采集的有限指向内容；地址变化属于指针变化，不把不同地址的成员认作同一目标。无需 qsort 专用 UI。主区宽度与摘要服务于数据，不强行填满空间。
