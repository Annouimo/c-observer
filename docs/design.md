# Observer 设计规范

Observer 是面向 C 语言课程的离线、只读运行观察器。帮助学生看清程序怎样改变数据，不重建 IDE 或通用调试器。

## 核心原则（按优先级）

1. **执行对应。** 以较早暂停点表示观察区间的执行上下文，以较晚快照展示数据状态。源码、变化、状态、输入输出对应同一时间线。变化始终来自相邻原始快照，不随导航方向改变；目前允许区间归因，不能假称精确单行归因。首帧是观察起点，结束页不是快照。
2. **数据真实性。** 仅比较身份可靠且可比较的值。区别已知不变、无法比较、新进入作用域、首次采集、退出作用域及数值改变；不能推断初始化、实际访问、逻辑数组长度或未采集值。区分未展示、未采集、无法读取与截断。
3. **变化突出。** 执行区提供简明前后值差异，数据区原位高亮。大量变化使用数量摘要，详情可查看全量已记录变化。变量变化检测是核心正确性问题，不因单行归因尚未解决而降级。
4. **信息精简。** 默认只展示理解当前执行所必需的信息。技术限制在相关对象上紧凑表达，完整解释按需查阅；不可因简洁隐瞒不确定性。颜色有明确语义：蓝色执行/焦点、绿色可靠变化/新增输出、灰色辅助信息、红色异常；关键状态不能仅靠颜色。
5. **数据优先。** 上方为紧凑的执行上下文与变化（左）、输入输出（右），共享有限高度；下方为全宽数据，底部进度与常用操作。小终端可退化为紧凑纵排。输入输出是核心信息，不再默认隐藏。完整源码、调用栈、预期输出按需展开。
6. **全局布局。** 同时考虑终端宽高，先给所有顶层对象最低可读概览。集中排列标量、短字符串等紧凑对象，大对象占剩余空间；优先变化、选择对象及相关上下文。完整/紧凑/概览候选按真实字符宽度选择。不以声明容量为隐藏理由，不为填满界面重复低信息量数据。允许留白。
7. **稳定回放。** 同一观察阶段的对象顺序、位置、列宽和预览范围尽量固定，必要时移动窗口以显示可靠变化；不因普通数值变化或导航方向而重排。默认观察当前帧与已采集全局/静态数据，不混淆不同递归帧。
8. **按需展开。** 详情提供完整已采集内容并支持继续回放。连续且确实相同的完整未截断元素可无损折叠。对于部分采集对象，允许仅折叠连续、已观察且未截断的相同预览字段，以 ≈ 明示预览相同而非整个对象相等；变化项及含可靠变化子项的预览不得折叠，不把缺采当重复。矩阵保留空间结构。保留类型化渲染（行式、索引列表、矩阵、表格、嵌套分组）。常用键位常驻，低频操作统一入口，用户不必管理面板。

前两条是正确性约束，不能为了体验优化而破坏。

## 第二轮体验完善计划

1. **记录基础设施（本轮 0.1.1）。** 主动导出版本化原始记录（冻结源码、字节级输入输出、预期输出、原始 RunResult、环境元数据），正式 CLI 离线回放。默认不落盘；确认导出、提示隐私及完整路径。详见 [record-format.md](record-format.md)。
2. **变化检测。** 收集维护者真实生日题记录，逐层定位采集/身份/比较/展示缺口，协调后端修复；不未经验证放宽身份规则。覆盖循环、同名遮蔽、递归和生命周期，区别无法比较与已知不变。
3. **视觉框架。** 恢复紧凑区域边界、标题、焦点及语法高亮；上方源码/变化与输入输出并列，下方全宽数据。不回到源码和数据各占半屏。
4. **数据布局。** 集中紧凑对象、无损折叠重复、变化优先预览、稳定列宽与全局空间分配。保留现有类型渲染器。
5. **输出与交互。** 按已记录字节偏移还原输出和高亮增量，跟随末尾；保留空格、换行和字符画。技术提示精简、统一操作菜单。输出缓冲另行验证，不伪造输出时点。输入消费位置独立预研已结束，依据副作用、平台兼容及性能结果保留静态样例。
6. **实机审核与发行。** 基于真实记录复现回放，审查原生 TUI，修复阻断问题后版本驱动发行。阶段 1 先独立发行，后续阶段不纳入 0.1.1。

## 验收

- 执行位置与前后状态对应；覆盖首帧、循环、调用/返回、递归、不可映射位置、结束及跳转。前进、后退、跳转至相同位置的可靠变化一致。
- 80×24、120×30、160×40 原生终端下测首屏对象覆盖、有效信息密度、变化显著性、布局稳定性、字符宽度及键位。CI 全绿、合成夹具和真实终端视觉审核不可互相替代。
- 保留典型压力案例：C6-D 多矩阵、E4-E 长整数、E4-G 嵌套数组、E6-E 递归与矩阵、E6-D 稀疏下标、E2.5-D 多标量和大数组。追加真实复习赛 B 生日题、A 签到表、D 不定行、J 字符串、Q 字符画、U 矩阵、Y 单行输入及 AE 字符矩阵。使用实际用户程序及样例，不将构造记录冒充实测。
- 记录导入导出需验证原始数据及每一步回放一致、无工具链运行、未知格式/损坏记录、空历史及不完整运行、隐私提示。区分实际测试与尚未实测平台。

现有 Engine.Run / RunResult 不变；底层快照仍表示暂停位置。阶段 1 记录外层封装由 TUI 持有，不改变后端与 Companion 会话协议。共享契约见 docs/interface.md；后续改动按 AGENTS.md 协调。
