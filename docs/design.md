# 下一代 Observer 前端设计

## 核心工作区

统一动态源码文档：以完整冻结源码为骨架，固定行号、源码列，可添加数据列；没有观察的行（声明、注释、空行、分支、花括号）必须保留，数据留空而非伪造状态。实际记录附着在对应位置，循环与函数调用尽量组织为可展开分组；时间顺序为无损辅助视图，输入输出为辅助视图。各视图共享变量选择；不另设调用栈、对象历史、快照筛选菜单、复杂自动关注、专业断点或时间线作为必需功能。

- 点击源码中的标识符添加/移除观察列。局部变量默认按函数名与名称匹配；全局变量使用已知全局分类；同一函数内同名变量可以组织在同列。类型/成员路径/真实下标辅助展示；同时出现多个候选则保留全部，不任意取一个。
- 点击行号查看该位置的所有观察状态（可展开每次的可见数据），能够返回完整执行文档。点击某次观察或数据单元格展开详情；数组元素和结构体成员可继续观察。
- 动态源码模式保持完整静态骨架，即使观察为空；折叠组内观察不重复附着到骨架的行，行号可直接查询所有原始记录。时间顺序模式保留真实观察顺序；未采集源码位置不伪装成已执行。选中变量列可跨模式保持。
- 默认比较相邻原始观察的可对应已读值；导航、筛选、折叠不改变比较依据。不是严格对象身份或赋值追踪，不能把不明确的区间变化归因于单条语句。未采集、不可读取、截断、无对应数据和未显示必须区分。
- 标量紧凑，普通行约 27–32px；函数/文件仅在需要时标注，观察编号展开全部状态。列标题移除列；顶部工具栏合并。小数据直接显示真实值，大数据优先显示已记录差异与有限预览，部分/截断作为辅助标记。数组元素、结构体成员可提升为普通观察列。差异用中性蓝色局部突出，不暗示正确性。折叠组摘要只显示实际相邻观察差异，不声称赋值归因。
- 输入输出保留原始输入、实际 stdout/stderr、预期输出及比较规则、运行状态。取消逐步骤输出字节展示；保留缺失和截断说明。

## 轻量结构识别

词法扫描识别标识符、注释、字符串/字符字面量、关键字及配对括号/花括号；共享给语法高亮和点击。以 for/while/do 等结构入口辅助对连续观察分组，以函数名、已有调用深度/上下文辅助函数折叠。支持典型普通及嵌套循环、分支、函数；简单实现优先。重复片段不必强行称为完整迭代；末次条件检查、break/continue、遗漏观察、复杂宏及无法识别结构保留原始观察，不能推造路径、条件结果或返回值。所有分组必须可展开为完全相同的观察序列。

不建设完整 C 解析器、控制流图、编译器级符号表、永久对象身份体系。用户理解自己的程序，Observer 提供可读的事实。

## 正确性与验收

源码是本次运行冻结文本，位置表示实际调试器暂停位置，不保证该行执行完成。保留调用上下文防止明显跨函数混淆；同名历史是近似组织。真实值、顺序和缺失状态不可牺牲。导入记录是本地数据，不执行其中源码；使用文本渲染，不把记录内容作为 HTML 或命令。

使用普通数值、数组修改、生日/签到表、排序、二分、矩阵和递归等典型课程程序验证。合成记录明确标识，不冒充实测。目标平台原生窗口验收不能被 CI 替代。

## 第三轮：统一阅读体验

循环头兼作分组开关；展开时只替换已经由组内观察呈现的静态循环体行，保留没有记录的源码、闭合结构和独立观察；折叠时恢复完整静态循环体。循环头重复暂停可简写，原始时间顺序保留全文。行号查询在点击位置内嵌，不切换到脱离源码的页面。小型数组/结构体采用跨观察固定成员布局（明确未知下标），较大数据采用紧凑摘要；单次复杂值详情使用临时对话浮层，不改变主表行高。分组摘要排除进入组前的跨边界差异，未变化标量可展示组首观察值。弱化横线和辅助索引，未观察源码正常高亮，使用数据列细分隔线。

## 第四轮：稳定空间坐标

动态源码默认保持原始行序及完整骨架，循环按实际推断观察组逐组选择，不为每轮重复源码。循环头保留组选择器和展开全部入口；嵌套循环在选定外层组内各自选择，无法分组的原始记录照常展示；时间顺序始终保留。组内未观察行留空，绝不借用其他轮的值。小型数据摘要和观察行共享成员坐标，同一成员的多次变化用次数及提示表达。公共成员名提取为上层表头；冻结行号与源码列，支持拖动列边界调整宽度。单文件直接显示文件名。开发期默认只打包 Apple Silicon Mac；Windows 仍为正式目标，按需手动构建，发行前双平台验证。
