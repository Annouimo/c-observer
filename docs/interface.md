# 前后端接口 v0 草案

状态：待 Codex 审核，不是冻结 API。Go 类型位于 internal/observer/model.go；本文件定义语义。只使用 Go 进程内接口，不引入 RPC。后端可以内部使用增量存储，但交付给前端的是不可变的自包含快照。JSON 仅用于测试及调试，不承诺外部稳定格式。

## 输入及会话
Engine.Start(ctx, LaunchConfig) 返回只读事件通道及启动错误。一次 Start 对应一次运行；重新运行创建新会话。Context 取消意味着停止采集并清理整棵子进程树。后端负责关闭通道；应在关闭前恰好发出一次 finished 事件（包含启动后编译失败、取消、异常等），之后不再发送事件。启动同步错误时不返回活跃会话。取消后消费者继续 drain 通道直至关闭；不得依赖 UI 持续消费来避免泄漏，后端需保证退出路径有界（具体缓冲/终止策略待审核）。
LaunchConfig 包含编译输入文件、工作目录、编译器/调试器可选覆盖、附加编译参数、用户可见源码、跳过规则、stdin 原始字节、可选预期输出与采集限制。所有路径通过明确的工作目录解析，不使用 shell 拼接用户参数。后端冻结每次运行的可见源文件内容并提供 started 事件；逻辑路径与调试位置一致，包括 #line。不要改写用户文件。编译及调试配置不覆盖正式评测。

## 事件顺序
started（包含来源、能力）→ 零或多个 snapshot/progress/diagnostic → finished → 关闭。
started 前编译或初始化失败可直接发 diagnostic/finished；无快照是合法结果。所有事件串行、有序；快照 ID 从 0 开始连续递增。事件的 payload 必须匹配 Kind。UI 可边采集边回放，默认跟随最新位置，用户回退不阻塞采集。
finished 区分正常退出（不等同 AC）、非零退出、信号/异常、超时、主动取消、采集上限、编译错误、后端错误。终止后保留已有历史。采集上限不暗示程序已完成。结果附最终已捕获输出，不能据此倒推未采集的历史。

## 快照语义
Location 是调试器当前暂停位置（下一步将从这里继续），不是刚执行完的一行。源级单步可能跨越多条表达式或整段辅助代码，不能宣称观测到所有赋值。Frame 按栈顶至栈底排序，ID 表示一次调用的身份，不得仅按函数名/深度识别递归。同一个变量在不同作用域、不同调用中必须区分；后端如果只能近似追踪，设置 identity_reliable=false，UI 不跨快照断言变化。作用域内未采集与离开作用域不同。
Variable 树：kind 为 scalar/string/array/struct/pointer/unknown；value 是显示文本，不要求前端解析 GDB 原始字符串；数组子节点提供实际下标，结构体提供字段名，嵌套递归。可选 array_length 表示声明容量，不是有效元素数量。children_complete=false 表示只记录部分子节点，历史中不可按需凭空获取缺失元素。status 区分 observed/not_captured/unavailable。observed 仅表示调试器可读，不证明 C 对象已初始化或值合法。字符串截断另行标志。变化比较仅针对相同身份、两端均可观察的同一数据；未采集不等于零，不在作用域不等于变化。
stdout/stderr 为截至暂停时已经捕获的原始字节前缀，受缓冲和异步读取影响，不声称准确归因到某行；输出截断必须显式标记。stdin consumed 可选，无法可靠测量时留空，不拿底层文件偏移冒充 scanf 消费进度。终端控制字符由前端转义。

## 初始限制（建议值，待实测）
最多 1000 快照、10 秒采集、每数组 32 个子元素、变量树深度 4、输出各 64 KiB、历史内存 32 MiB；零值表示使用安全默认，不表示无限。数组采集范围暂定前缀；用户调整范围需重新采集，不承诺历史回填。后端还必须限制单次调试请求并可靠清理进程。若截断发生，明确告知原因。
Capabilities 表示真实后端支持情况，不以平台名称猜测；全局、精确身份、输入消费、用户回调等均可降级。
