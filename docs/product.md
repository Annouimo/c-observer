# 产品定义：替代 printf 调试

状态：下一代 GUI（拟 0.2.0）开发规范，尚未发行。

C Observer 是面向 C 语言课程的离线、只读程序运行观察器。它的核心目标是降低学生使用 printf 查错的时间成本，不是提供功能简化的 GDB。把一次程序运行转换为可以交互阅读和查询的数据文档。

## 用户与范围

典型对象是几十至几百行、单文件 C99 课程程序，预设 stdin、小样例、可复现的短运行。重点是普通变量、数组、结构体、循环、条件、函数及常见递归；不追求覆盖任意合法 C 程序。独立使用或由 Companion 传入会话；不生成解题代码，不联网，不编辑源码，不自动修改程序。考试使用遵守课程规定。

## 原则

- 替代 printf 调试，而非替代 GDB。按实际查错收益与维护成本取舍。
- 源码即索引，执行即记录，点击即查询。用户选择源码和数据，而不是专业调试器功能。
- 面向典型学生程序，而非任意程序。优先名称匹配、轻量词法扫描与实际观察记录。
- 尽力识别，无损退化。控制结构分组是展示推断；无法识别则平铺原始记录，不篡改观察顺序和值，不把未知当作零或未执行。
- 前端决定最小必要信息，后端负责真实采集。避免为低频例外建设严格运行时身份、完整 AST 或通用控制流重建；重新运行成本低时，不引入不必要的状态机制。

## 基本工作流

选择源码与样例（或 Companion 会话）→ 运行并采集 → 阅读执行文档、点击变量/行号 → 外部编辑器修改 → 重跑。保留原始源码、输入/实际输出/预期输出、异常和不完整记录、导出和离线回放。首版使用现有记录与引擎；不承诺捕获每条 C 语句或表达式。

## 环境基线

Windows 11 x64 使用课程提供的一键 GCC 16.2.0 工具链安装包（维护者已解决安装及 PATH 配置）；macOS Apple Silicon 使用现有 Clang/LLDB 工具链。停止旧 Dev-C++/旧 MinGW 兼容研究，不扫描 IDE、不自动安装工具链、不扩大平台矩阵。仅对实际基线失败提供可操作提示并修复。具体 GUI 技术决策见 [实验决策](../experiments/webview/DECISIONS.md) 与 [GUI 实施规范](frontend-next.md)。

## 验收

在真实课程题目上验证能否比 printf 更快查错、减少用户操作及学习成本；观察值真实、缺失可辨、循环折叠可恢复原始顺序；两目标平台离线运行。实现成本相近时优先更简单方案。
