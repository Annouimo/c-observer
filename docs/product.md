# 产品定义：替代 printf 调试

状态：下一代 GUI（拟 0.2.0）开发规范，尚未发行。

C Observer 是面向 C 语言课程的离线、只读程序运行观察器。它的核心目标是降低学生使用 printf 查错的时间成本，不是提供功能简化的 GDB。一次采集，多次回看：拖动观察时间线，查看任意真实暂停时刻的程序数据。

## 用户与范围

典型对象是几十至几百行、单文件 C99 课程程序，预设 stdin、小样例、可复现的短运行。重点是普通变量、数组、结构体、循环、条件、函数及常见递归；不追求覆盖任意合法 C 程序。独立使用或由 Companion 传入会话；不生成解题代码，不联网，不编辑源码，不自动修改程序。考试使用遵守课程规定。

## 原则

- 替代 printf 调试，而非替代专业调试器。主要任务是回答运行到这里时数据是什么。
- 单一简洁界面；尽可能少的操作获得尽可能多的有效信息，屏幕优先展示重要信息，视觉焦点稳定。已经实现不是保留功能的理由；无明确查错价值的界面及逻辑删除。
- 数据是主体，时间是全局坐标，源码是上下文。只显示真实观察时刻的数据，不拼接全程最近值。
- 时间线可直接拖动；点击数据模块或成员，在同一时间线上标记其已知变化，快速跳转。布局跨时间稳定。
- 面向典型学生程序，简单实现，保留真实记录、未知与截断语义；名称匹配不等同于严格对象身份，不建设完整 AST 或控制流重建。

## 基本工作流

选择源码与样例（或 Companion 会话）→ 运行并采集 → 拖动时间线观察数据、点击对象定位变化 → 外部编辑器修改 → 重跑。保留原始源码、输入/实际输出/预期输出、异常和不完整记录、导出和离线回放。首版使用现有记录与引擎；不承诺捕获每条 C 语句或表达式。

## 环境基线

Windows 11 x64 使用课程提供的一键 GCC 16.2.0 工具链安装包（维护者已解决安装及 PATH 配置）；macOS Apple Silicon 使用现有 Clang/LLDB 工具链。停止旧 Dev-C++/旧 MinGW 兼容研究，不扫描 IDE、不自动安装工具链、不扩大平台矩阵。仅对实际基线失败提供可操作提示并修复。具体 GUI 技术决策见 [实验决策](../experiments/webview/DECISIONS.md) 与 [GUI 实施规范](frontend-next.md)。

## 验收

在真实课程题目上验证能否比 printf 更快查错、减少用户操作及学习成本；观察值真实、缺失可辨、拖动与变化跳转保持原始次序、布局稳定；两目标平台离线运行。实现成本相近时优先更简单方案。
