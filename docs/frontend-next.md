## 第一阶段：离线 GUI 原型

使用现有 v1 JSON 记录和合成 fixture，不改 Engine.Run / RunResult，不接入采集，不改 Companion 协议、VERSION 或 npm 发布工作流。GUI 核心不依赖 Wails 专有 API；原型可以在浏览器开发预览，并通过已验证 Wails 壳构建。仅原型阶段允许独立 Go 模块以隔离主模块，接入引擎时再整合。生产入口与旧 TUI 暂不动。

优先：导入记录、完整源码、执行表、点击变量增减列、点击行号查询状态、类型化数据展开、相邻值比较、轻量循环与调用折叠、输入输出。缺失状态及原始观察顺序必须保持。先平铺后分组；以真实记录反馈确定默认展开策略。导入不执行 C。无需预先构建复杂组件库、状态管理库或分页通信。

## 第二轮离线原型修订

以完整冻结源码为默认动态文档，保留无记录行，附着观察、循环和调用；保留时间顺序视图、行号原始查询。紧凑单行、列标题删除、数组预览/变化及成员列、折叠摘要。先支持典型带花括号循环和简单单语句循环，识别不可靠时保持原始记录；不因 GUI 引入后端分析。验收 wrong-index 的 1–13 行全貌及 8,9,7 重复两组、每个快照可查、部分数组真实下标和变化。真实记录及双平台视觉验收仍需完成。
