# 数据优先回放：实施计划

长期规范见 [design.md](design.md)。本轮仅重构前端，不更换调试引擎、不修改 Companion、不发布版本。在 feat/data-first-replay 上实现，保留原有采集、重跑、历史、数据详情及输出对照能力。

## 实施顺序

1. 执行语义：ReplayStep 使用真实相邻快照，不减行号、不将变化归于后一个暂停点。首帧为观察起点，结束不是快照。现有引擎没有单行完成证据；区间变化必须明确标注，精确归因需与引擎侧协商契约和真实测试。
2. 主界面：少量执行上下文和变化摘要，全宽数据区；源码、输入输出、栈帧按需访问。保留既有导航、详情、历史和重跑入口。
3. 展示系统：为所有根对象保留最低可读空间，按宽高分配剩余预览空间；短值数组横排、长值索引列表、矩阵子表、嵌套分组。完整/紧凑/概览自动选择；范围、列宽、顺序在连续回放中保持稳定。
4. 详情与状态：保留真实下标及原值；明确未展示、未采集、无法读取和截断；支持详情回放及已记录范围浏览。
5. 验收：80×24、120×30、160×40 字符快照，覆盖多矩阵、18 位整数、嵌套数组、递归、稀疏下标、大量普通变量及原有夹具；真实 GDB/LLDB 回放与原生终端审核单列。

## 本轮实现与边界

默认视图使用全宽数据区，以终端宽高选择布局：先保留对象标题，再尽量展示小对象及大型对象预览。按 C/I/S 打开源码、输入输出、调用栈；按 D 查看详情，T 切换全部已采集成员，Enter 查看选中单元格的采集原值。详情内左右键仍按时间线回放。

有限空间内省略的已采集值在数据区提示；读取失败、未采集和采集截断各自显示。布局从整段历史预估值宽；作用域、所选帧、采集范围或窗口尺寸改变时可以重新排列。筛选及跳转始终比较原始相邻快照。

精确单行归因留待体验验收后决定。本轮通过前后暂停点表达采集区间，单行归因不作为交付门槛。输出按已采集字节展示。
