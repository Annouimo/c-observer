# 前端优化：macOS 体验版

已获维护者批准。基于已审核的阻塞 Engine.Run / RunResult；本地联合调试成果尚未全部反映在远程主分支。保留 Codex 工作，不修改共享接口或正式入口，先在 feat/tui 上迭代，最终共同合并并联调。

## 设计原则
单工作台，默认源码/数据双栏、底部输入/输出、固定历史导航及按键提示；窄屏按区域切换，允许最大化。类型化数据显示优先于树：标量表、字符串文本、一维数组按下标排列、矩阵行列、结构体字段及结构体数组共享表格；根据实际展示成本决定是否折叠，而非声明容量。复杂嵌套保留详情。源代码暂停行和浏览行分开；选栈帧不改变真实暂停点。

自适应关注范围：整个已采集运行记录内，对可靠身份对象的相邻可比较值变化取最小闭区间（一维与记录数组两端各 2 项）或矩形（二维各 1 行列）；与已采集边界相交。回放固定范围，缺失元素标未记录，无变化/身份不可靠时完整显示，允许恢复完整采集数据或手动设展示范围，采集范围重跑另行设置。不能据此判断初始化、使用或逻辑长度。触及采集边界提示。只对已记录历史成立。

历史索引一次建立，保留原始快照序号。全部快照、任意可靠变化、选中对象变化、选中源码行停靠点四类导航；与原始相邻快照比较而非筛选后的前一帧。H 历史、F 筛选、M 最大化、J 跳转、? 帮助；Enter 详情/确认，Esc 返回，Tab 区域，方向键时间/局部。对象菜单提供低频操作；兼容 D/A 快捷入口。栈帧按可靠 ID 跨暂停保留，否则回到栈顶。

输入输出并排；最终结果独立显示，不伪造暂停快照。差异仅是输出比较而非 OJ 判定，转义控制字符，明确截断；异常保留历史。启动页支持路径、输入粘贴/导入、可选预期输出、快速重跑，复用现有工具链配置，不做文件管理器。

## 实施与验收
1. 历史索引、可靠变化及关注范围；无跨快照身份的真实后端必须降级。
2. 主工作台类型化渲染、最大化、栈帧、源码选择；宽窄终端与中文。
3. 导航、对象菜单、历史定位、帮助、跳转。
4. 输出对照、配置和错误体验。
5. 与 Codex 最新引擎联调，真实课程题目和 macOS/Windows 终端视觉验收，更新规范并合并。

测试覆盖零值、1-based、非前缀页、稀疏变化、无变化、不可靠身份、同名变量、递归、多帧、缺失数据、运行结束/异常、重跑与取消。真实记录单列来源；不将合成数据或 CI 编译当真机联调。暂不做内存访问追踪、实时调试、逆向执行、AI、源码编辑器和复杂算法动画。
