## 已完成的技术预研

[WebView 报告](../experiments/webview/TEST_REPORT.md) 和 [平台决策](../experiments/webview/DECISIONS.md) 为依据：Go 1.26、Wails v3.1.0、Svelte 5、TypeScript、Vite，系统 WebView；Windows 11 x64、macOS arm64 真机基础窗口和离线启动通过。Windows GUI EXE、macOS APP ad-hoc 签名，不做可信签名、公证、运行时自动安装、额外安装器或 TUI 回退。仅支持两目标平台。实验不证明业务引擎、完整分发或性能已经验收。固定依赖锁文件后再进入正式发行。

Windows 工具链基线为维护者提供的一键安装 GCC 16.2.0（含新版 GDB、自动配置 PATH），不研究旧 Dev-C++ 兼容、不建设 IDE 扫描或工具链安装。macOS 沿用现有 LLDB。发生实际基线问题才调查。

## 第一阶段：离线 GUI 原型

使用现有 v1 JSON 记录和合成 fixture，不改 Engine.Run / RunResult，不接入采集，不改 Companion 协议、VERSION 或 npm 发布工作流。GUI 核心不依赖 Wails 专有 API；原型可以在浏览器开发预览，并通过已验证 Wails 壳构建。仅原型阶段允许独立 Go 模块以隔离主模块，接入引擎时再整合。生产入口与旧 TUI 暂不动。

优先：导入记录、单一数据优先工作区、稳定类型化布局、当前暂停源码上下文、实时可拖动观察时间线、直接点击数据标记相邻变化、前后变化跳转、输入输出临时查看。删除执行文档、循环/调用折叠、手动列与平行视图。完整快照不跨时刻拼接，缺失和截断语义保持。导入不执行 C。开发期 CI 默认仅构建 Apple Silicon Mac；Windows 手动启用，发行前双平台验收。

## 数据优先优化

恢复旧 TUI 的相邻执行区间对应、紧凑样例预览、样例规则与原始字节对照；以历史形状/宽度估计自然尺寸和当前函数布局，保守压缩稳定相同的连续数组元素，时间线标记合并绘制、变化索引有限缓存。复用旧压力夹具验证逻辑，不新增引擎接口。原生拖动性能与实际窗口空间利用率须维护者验收。
