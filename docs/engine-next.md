# Codex 下一阶段任务：观察引擎完善

状态：初步 LLDB 前后端联调已成功（维护者反馈），进入 macOS 体验版完善阶段。以最新实际代码为准：若本地已有未推送的联调成果，先保留并核对，避免重复实现或覆盖。

## 目标与分工

C Observer 是面向 C 语言课程的离线、只读程序运行观察器。针对单文件、小样例、短生命周期程序；以自动采集、历史回放和变量变化为核心，不做通用调试器。使用 Go，保持已有阻塞式 Engine.Run / RunResult 接口。不需要重新验证技术栈，也不做实时单步、逆向执行或 AI 解题。

Codex 负责 internal/engine/**、真实 C 夹具与底层测试；ChatGPT 负责 internal/tui/** 及其交互设计。共享接口、正式入口及依赖改动先协调。先对齐真实联调基线，按短功能分支提交 PR，不覆盖对方未合并工作。不修改 Companion。

## P0：macOS 体验版核心能力

1. **跨快照身份（最高优先级）**。现有远程 LLDB 实现使用快照内 frame/object ID，未设置可靠身份，导致真实 TUI 不能高亮变化或查询变量历史。先覆盖 main 中的标量、数组、结构体与成员，再处理普通调用、递归、同名遮蔽和重复进入作用域。可靠 ID 在一次运行内不得复用；不能证明连续身份时保持 IdentityReliable=false。不能仅凭名称、栈深、临时 DAP 引用或地址相同断言同一对象。实测生命周期边界；保持已有接口，必要调整另行协商。
2. **自动观察用户函数**。默认记录用户源码中的函数及 qsort 比较回调，跳过标准库和明确标记的 C Exam Kit 辅助源码。优先复用调试器符号和停靠能力，不引入重型 C parser。考虑间接调用及回调；仅显式停靠可用时如实降级。验证不会陷入库内部、漏掉常见用户调用或重复停靠失控。
3. **全局与静态对象**。支持常见全局大数组、计数器、DFS 数据；能区分参数、局部、文件静态、函数静态与全局时填 Scope，完整性标记真实；不重复计算同一静态对象，不为不确定身份制造变化。维持数组分页、节点/深度限制。
4. **有界运行和资源清理**。测试无限循环、大量输出、请求超时、异常终止、取消与连续重跑。当前 stdout/stderr 临时重定向文件可能增长，历史预算为编码快照大小而非实际堆内存；评估实际资源占用并采取必要的轻量限制。不能牺牲数据语义或留下运行进程；记录清理失败。保留已采集历史，明确未正常结束的原因。
5. **真实验收与性能**。用实际 Clang/LLDB 在 macOS 和 Linux（支持环境）测试：求和、冒泡、二分、生日查询误用 i/index、qsort 布尔比较、字符串统计、递归、全局二维数组/DFS、多组数据未重置、除零、无限循环、大容量小样例。覆盖 #line 映射、中文/空格路径、输入输出、数组非前缀页、失败与取消。测端到端等待时间、快照数、内存/临时文件、清理时间；按结果调整默认预算，不将预研协议摘要耗时当产品耗时。优先提供能给前端复用的真实 RunResult 记录（标明环境、源码与输入，区别于 synthetic fixtures）。

## 验收与提交

每个 PR 说明范围、实际测试环境、已支持与降级场景，运行 gofmt、go test ./...、go vet ./... 和适用的真实调试器测试（参见 internal/engine/README.md）。跨快照测试应断言可靠身份和真实值变化，同时包含不应匹配的反例；回调测试须证明实际进入用户 cmp，不只检查断点请求成功。不要把程序正常退出等同 AC。保留原始源码/正式提交代码，不把诊断构建改动混入评测。

遇到接口小问题优先记录并继续不受影响的工作；不能可靠获取的数据允许降级。阶段结束提交简短报告、真实记录和可复现命令，并更新引擎 README。此文件为本阶段任务入口；AGENTS.md 规定职责，docs/interface.md 规定数据语义。前端 UI 细节由 ChatGPT 与维护者另行讨论。
